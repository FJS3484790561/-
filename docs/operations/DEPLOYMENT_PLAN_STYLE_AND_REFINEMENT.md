## 部署前检查

- 备份生产 SQLite 数据库、COS 元数据和上传对象；校验备份可独立读取。
- 确认服务器运行版本与待部署提交号一致；不得直接覆盖 `.env.production`。
- 核对图片编辑 Provider 的端点、双图协议、模型、费用和超时；密钥只通过服务器环境变量或管理页面输入，不写入命令、日志、截图或 Git。
- 先在备份或维护窗口执行 SQLite schema migration，确认 `user_styles` 表和回滚备份存在。
- 部署后依次检查健康接口、管理员登录、Provider 双参考测试、用户登录、风格保存/隔离、生成、COS 写入/读取、额度扣点和失败释放、trace ID/脱敏日志。

## 回滚

停止应用进程，保留新日志和数据库副本；恢复上一版本构建与上一份数据库备份，重新执行健康检查和生成失败释放检查。不得通过删除 `user_styles` 数据或修改 `.comet` 历史来回滚。
