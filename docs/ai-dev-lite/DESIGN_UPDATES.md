## 注册与邮件

公开 `POST /api/auth/register` 必须提交邮箱、密码、6 位 verificationCode。`POST /api/auth/register/code` 发送验证码。验证码有效期 10 分钟、重发间隔 60 秒、每个邮箱每小时最多 5 封、每个实际连接地址每小时最多 10 封、每次验证码最多尝试 5 次。验证码只存 HMAC 摘要，不写日志、不从 API 返回；校验与建号/消费在事务中完成，支持 SQLite 重启和跨连接竞争。

SQLite 增量迁移 5 新增 registration_challenges。旧账号可继续登录，不伪造其 emailVerifiedAt。测试通过内部 provisionUser 准备历史账号；公开接口没有跳过验证开关。

SMTP 配置变量：SMTP_HOST、SMTP_PORT、SMTP_USER、SMTP_FROM、SMTP_PASSWORD。最后一项通过服务器私密环境配置，不发送到聊天，不提交 Git。465 使用 TLS，其他端口强制 STARTTLS，启用证书校验，禁止 SMTP 调试日志。没有邮件配置时发送失败，注册保持关闭。

QQ SMTP 已通过服务器 TLS、身份认证，并被 QQ SMTP 接受一封测试邮件；邮箱收件确认仍待用户核对。授权信息只保存在服务器私密环境中。HTTP 适配层仅在连接来源为本机回环地址时读取 Nginx 固定覆盖的 `X-Real-IP`，并严格校验为单一 IP；公网连接不能用转发头伪造限流身份。

## 风格与提示词

- 中古风、侘寂风均添加相应英文风格说明和图片卡片。
- 两张新增本地图片裁自用户本轮上传的参考拼图，不含原拼图标签；用途为本地效果预览。对外发布前确认使用权，必要时替换为自有图片。
- 原有卡片以前显示照片，但发送 Canvas 色块示意图。现在读取卡片实际构建资源，转为图片上传参数；读取失败不使用假图替代。
- 自定义入口位于预设及已保存风格最后，为加号卡片；弹窗上传图片、填写名称/描述，保存后生成用户私有卡片。
- 修复旧自定义风格上传时把 fileToImage 外层对象误当图片 payload 的问题。
- 首次生成可填写最多 2000 字额外要求，服务端独立校验长度；有关家具保留的用户要求优先于默认家具更换，固定建筑结构约束仍有效。

## 连续修改和版本

新增 `POST /api/generations/:id/revisions`。服务端校验当前用户拥有该成功任务，从该任务的已存储结果读取图像，不接受客户端指定任意结果 URL。生成以当前结果为第一参考图，以本次设计的风格照片为第二参考图。局部修改使用独立提示词，不再附带整屋大改指令。

每次生成保存 parentTaskId/rootTaskId，改造前图始终保留最初房间图。新结果成功后自动成为当前效果；失败不替换当前效果。回退沿父节点，可点击本次任一版本后继续生成分支，旧分支不会被删除。保存作品/下载指向当前选中的结果。

本次版本列表保存在工作台内存中，刷新/离开工作台后列表清空；页面明确提醒先保存满意版本。后端已生成任务和对象仍沿用现有持久化机制，本次未新增清理历史对象的操作。跨设备完整版本管理不在本次范围。

已获得任务 ID 后查询中断，可重试查询同一任务，不重复提交生成。若提交请求本身断网且未获得任务 ID，结果可能未知，不能根据网络错误推断未扣点。
