# 图片编辑 Provider 书面询证模板

请项目所有者通过供应商官方工单、客服或其确认的支持渠道发送。不要附带 API Key、服务器密码、用户照片或任何生产配置。

## 可直接发送的内容

您好，我们准备在一个室内设计 MVP 中使用 `gpt-image-2` 对用户上传的原房间照片进行图片编辑，而不是纯文字生图。请提供官方文档链接或逐项书面确认以下内容：

1. 是否支持上传原图进行图片编辑？准确的 HTTP 方法和完整端点是什么，例如是否为 `/v1/images/edits`？
2. 认证是否为 `Authorization: Bearer <TOKEN>`？请列出 multipart 的准确字段名及必填/可选规则，包括 `model`、`image`、`prompt`、`size`、`n`、`response_format`，以及是否支持 `mask` 或多张参考图。
3. 哪些模型支持图片编辑？`gpt-image-2` 是否支持？原图允许 JPEG/PNG 中的哪些格式，最大文件大小、像素尺寸、长宽比、透明度和数量分别是多少？
4. 支持哪些输出尺寸和质量参数？成功响应是 `data[0].url`、`data[0].b64_json` 还是其他结构？URL 有效期多久？
5. 请提供 400、401、403、413、429、5xx、内容安全拒绝和超时的错误结构。请求超时后是否可能继续生成并计费？失败、内容拒绝、429、5xx 和客户端断开是否计费？
6. 单次图片编辑如何计价？请给出按模型、尺寸、质量和分组计算后的人民币或余额扣费示例，并说明是否可能出现“返回 524 但实际上已经生成并扣费”的情况。
7. 上传原图和生成结果是否留存？分别保存多久、用于什么目的、能否关闭训练或二次使用、如何删除？数据在哪个国家或地区处理和存储，是否存在跨境传输或第三方再处理？
8. 是否有适用于生产服务的服务条款、隐私政策、数据处理协议、内容安全政策、速率限制和可用性说明？请提供链接及版本日期。

我们的预期请求是一次调用、不自动重试，通过 multipart 上传一张 JPEG/PNG 原图，并要求尽量保持房间几何结构和视角。请明确该用法是否受支持。谢谢。

## 可接受的证据

- 供应商官网公开文档链接；或
- 官方工单/客服的可核验书面回复，包含日期和回复渠道。

口头描述、群友推测、仅有文字生图调用示例，或者只写“支持编辑”但没有端点和字段，不足以解除阻塞。
