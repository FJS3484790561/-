# 生产付费 MVP

## 账户与免费内测

- 用户使用邮箱和密码注册、登录和退出，并可通过一次性邮件链接找回密码。
- 找回密码的响应不得泄露邮箱是否已经注册。
- 免费内测默认允许公开注册，管理员可随时关闭或重新开放注册。关闭时新用户无法注册且页面明确提示暂停注册，已有账户仍可登录。
- 新用户须先完成邮箱验证，账户才激活、获得一次 3 点额度并具备额度码兑换资格；每个账户的注册赠送只能发放一次，额度记录由服务端保存并可审计。
- 免费内测期间，用户可通过管理员生成的额度码获得额外额度。
- 切换到正式收费版时，不继承内测账户、作品或额度；内测业务数据按受控流程清理，正式用户需要重新注册。

## 额度与生成

- 1 点额度对应一次成功生成。Provider 超时、拒绝或失败不扣额度，系统不自动重试，用户可手动再次生成。
- 免费额度、额度码兑换所得额度和购买额度自到账起 12 个月有效；服务端是余额、扣减和到期状态的权威来源。
- 登录用户可上传合规的 JPEG 或 PNG 图片，选择现有的房间、风格、改造强度和偏好后，通过服务端调用真实第三方生图 Provider。
- 每次请求返回一个结果。作品包含原图、结果图和生成信息，可跨设备查看、下载，并使用支持指针及键盘操作的前后对比滑块查看。
- Provider 由管理员在后台选择和配置，系统保留更换 Provider 的能力；浏览器、用户响应、日志、前端产物和数据库明文字段不得泄露 Provider 密钥。

## 额度码

- 管理员可生成共享额度码，并为每个码填写每位成功兑换者获得的 1-200 点额度、最大成功兑换人数和兑换截止时间。
- 兑换截止时间默认为额度码生成后 30 天，管理员可在生成时调整。
- 同一账户对同一个额度码最多成功兑换一次。达到最大兑换人数、超过截止时间、无效或重复兑换均不得增加额度。
- 成功和失败的兑换尝试需要保留必要的审计信息；并发兑换不得突破最大兑换人数或重复加额度。
- 兑换所得额度自成功到账起 12 个月有效。

## 支付与订单

- 首期只接入微信支付，支付宝、订阅制、优惠券和退款自动化留作后续 Change。
- 用户可选择 1-9 元的整数充值金额，按 1 元兑换 1 点；也可购买 10 元/12 点、30 元/45 点或 100 元/200 点额度包。
- 支付订单、回调验签、金额核对、状态流转和额度到账由服务端完成。回调必须幂等，同一订单不得重复增加额度。
- 营业执照、域名备案和微信支付商户号完成前，不开放充值或真实扣款，只允许免费内测和支付测试环境验证。

## 数据、部署与运行

- 账户、会话、作品、订单、额度、兑换码和审计记录使用生产数据库持久化，服务重启后不得丢失。
- 图片使用对象存储，数据库和必要对象具备异地备份、恢复验证和可执行回滚步骤。
- 中国大陆生产环境使用腾讯云的单区精简部署，通过已备案域名和 HTTPS 提供服务；月基础设施预算控制在 300 元以内，不含生图 API 用量。
- 服务具备健康检查、结构化脱敏日志、关键告警、速率限制、安全响应头，以及上传、CSRF、SSRF、权限和内容安全保护。
- 生产凭据仅来自部署环境变量或密钥管理服务，不进入 Git、文档、日志、截图或前端代码。

## 发布边界

- 自动化测试、代码检查、构建、依赖安全检查、支付测试环境、备份恢复以及桌面和 320-390px 移动端核心流程均需形成独立验收证据。
- 远程推送、域名购买、备案提交、生产部署、生产凭据配置、真实扣款和正式发布均不由本规格自动授权。
- 只有生产验收证据齐备且用户另行明确批准发布后，才允许正式收费上线。

## 非目标

- 支付宝、订阅制、优惠券、团队账户、批量生成、自定义提示词、用户自有 API 密钥和多区高可用不在首发范围。

## 决策与事实记录

DECISION: 免费内测使用邮箱验证、首次 3 点、管理员注册开关和共享额度码；正式收费版不继承内测数据。

DECISION: 首期使用微信支付、腾讯云国内单区部署和按次付费的可更换第三方生图 Provider。

DECISION: 真实部署、真实扣款和正式发布必须在证照与验收完成后另行批准。

FACT: 当前代码已经具备本地用户端、管理员端、HTTP API 和 Provider/支付适配边界，但仍缺生产数据库、真实邮件、真实支付、真实生图服务和生产部署。

IMPLEMENTATION_CHOICE: 在不固定供应商品牌的前提下沿用现有服务边界，通过可配置适配器接入首个满足合规、成本和接口要求的 Provider，避免把供应商凭据或专有调用暴露给浏览器。
