# Design System

DESIGN_SYSTEM_STATUS: DRAFT

- Color: pale warm/pink/lilac background; rose primary; mint original-photo state; lilac generated state; amber notice.
- Typography: rounded Chinese-friendly UI face; restrained display face for workbench heading; explicit control typography.
- Spacing: generous 8-based rhythm; 44px minimum primary targets.
- Radius: large rounded surfaces and pill actions.
- Elevation: combined soft outer and inset shadows; no hard-edge shadows.
- Motion: spring-like hover/press feedback with reduced-motion alternative.
- Components: app shell, nav, select, segmented strength, preference checkbox, upload/result stage, comparison slider, action button, credit notice, status message.
- Accessibility: visible focus, keyboard operation, no color-only status, responsive 320-390px support.

DESIGN_SYSTEM_APPROVED: NO
